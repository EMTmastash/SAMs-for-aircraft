### SAMs-for-aircraft
Adds SAMs(R9, RAM-45, NL-98) to aircraft.

## NEEDS BLUEPRINTER TO RUN
[Get Blueprinter](https://github.com/nikkorap/NOBlueprinter-Releases/releases/latest)

## Features
- R9, R45, NL98 missiles for aircraft
- R9, R45 has real SARH guidance, requires a radar airframe, keep the target in your radar cone
- Missile track status for SARH missiles, displayed above fired missiles icons, **TRACK** or **NONE**, none includes track memory
- Event weapon: R9 variant with 1.5kt nuclear warhead.
